# 12. Agent guidance from Markdown

## Status

Accepted

## Context

An external agent needs guidance when it connects and when the learner moves between onboarding, Track building, practice and review. Learners and contributors also need to read these workflows on GitHub. Maintaining separate copies would allow a client to receive advice for a different version of a Tool.

## Decision

Keep the English source in `docs/agent-guide/`. Each Markdown file has an ID, title and order. The opening paragraph of the platform section supplies the MCP initialize instructions. Each workflow section opens with its recommended Tool calls.

Run `pnpm guide:build` after editing the source. Commit the generated JSON alongside its Markdown source. The server imports it into the bundle. `pnpm guide:check` compares the generated bytes with the current Markdown and runs as part of `pnpm check` in CI.

Expose the sections as named Markdown resources under `startodel://guide/<id>` using the installed SDK. The `get_guide` Tool selects relevant sections using only the token Owner’s Profile and progress. It returns their content, the current counts and the reason for each next step. Clients can use the Tool independently of resource support.

## Consequences

The runtime serves the same guidance from a production image or a checkout. It needs no filesystem access to the documentation. Adding a Tool requires updating the guide and verifying isolation over HTTP. The generated artifact makes guide changes reviewable and adds a freshness check to the contributor workflow.

## Amendment — installable agent skills

Generate the installable workflows in `packages/skills/skills/` from the same Markdown as the MCP resources. Each entry in `scripts/skills.mjs` selects a primary section and any supporting sections. The primary section supplies the skill description through its `skillDescription` field. Every workflow ends with the shared rules.

Commit the output of `pnpm guide:build && pnpm skills:build` with the source. CI runs `skills:check` through `pnpm check` and reports edited, missing and extra files.
